Project Name: 🛒 বাজার দর (BazarDor)

Short description: 
Today's essential grocery prices, all in one place. Track rice, lentils, oil, vegetables, fish, meat, eggs and spices, with market-wise prices across Bangladesh. Next.js TypeScript Tailwind CSS DaisyUI BetterAuth MongoDB

📖 About The Project

বাজার দর (BazarDor) is a web app that helps people check the daily prices of everyday grocery items in Bangladesh. Instead of visiting many markets or asking around, you can open BazarDor and quickly see:
    1. what the price of a product is today,
    2. whether it went up or down compared to yesterday,
    3. which market has the cheapest and the most expensive price.

The whole interface is in Bangla, so it is easy for everyone to use. It is fully responsive and works well on phones, tablets and desktops.

🛠️ Technologies Used
Next.js 16 (App Router)	Building the UI, routing, server-side data fetching
TypeScript	Type-safe code and fewer bugs
Tailwind CSS v4	Styling and responsive design
DaisyUI	Ready-made UI components (buttons, cards, badges, skeletons)
BetterAuth	Authentication (email/password, Google, GitHub)
MongoDB Atlas	Stores users and sessions
React Hot Toast	Toast notifications
Vercel	Hosting and deployment


✨ 5 Key Features
1. 📊 Live Daily Prices
See today's price of every product with a clear up ▲ / down ▼ badge compared to yesterday. A scrolling price ticker at the top keeps the latest changes always visible.

2. 📂 Category Pages with Sorting
Browse products by category (rice, lentils, oil, vegetables and more). You can sort the list by price: low to high or high to low.

3. 📦 Detailed Product Page
Each product has its own page with a price summary (lowest, highest, average) and a market-wise price table that shows prices from different markets and divisions.

4. 🔐 Secure Authentication
Sign up and sign in using email & password, Google or GitHub. Protected pages (like the profile page) redirect to the sign-in page if you are not logged in.

5. 👤 Profile Management
Logged-in users can see their profile (photo or avatar, name, email) and update their name. A success toast confirms the change.
